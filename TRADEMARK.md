# Trademark Policy

This document is the trademark policy for the Helpmefindthejob project. It is
deliberately separate from the [LICENSE](LICENSE) file because copyright and
trademark are two different things and the Apache License 2.0 explicitly does
**not** grant trademark rights (Apache 2.0 §6).

## Scope

"Helpmefindthejob" — and any project logo, wordmark, or visual identity that
the maintainers publish in this repository or under a `helpmefindthejob` org —
are the unregistered trademarks of the Helpmefindthejob maintainers, used in
the course of identifying this specific project and its reference
deployments.

The source code in this repository is licensed under [Apache License,
Version 2.0](LICENSE). That gives every recipient broad rights to use,
modify, and redistribute the code. Those rights do **not** extend to using
the project's name or marks to:

- imply endorsement of a fork, derivative, or commercial offering by the
  upstream maintainers
- present a fork as the canonical Helpmefindthejob
- claim a partnership, sponsorship, or affiliation that does not exist

If you fork or modify the code and distribute it under your own brand —
which the Apache 2.0 license fully permits — please pick your own project
name and your own marks for that distribution. You remain free to state,
truthfully, that your fork is based on or derived from Helpmefindthejob.

## Permitted nominative use

You do not need our permission to:

- refer to "Helpmefindthejob" by name in articles, blog posts, talks, academic
  papers, social media, or any descriptive context
- link to the upstream project's repository, documentation, or website
- describe interoperability ("compatible with Helpmefindthejob", "exposes the
  Helpmefindthejob MCP catalogue")
- include the unmodified name in attribution notices required by the LICENSE
  and NOTICE files

We ask only that nominative use does not falsely imply endorsement.

## Use in derivative work names

If you publish a fork or derivative that materially diverges from this
project — different goals, different governance, different scope — please
choose a name that is distinct enough that users will not be confused. A
name that starts with `Helpmefindthejob` or contains the full mark as a
prefix is too close; a name that references the project descriptively
("`fooagent`, a tool inspired by Helpmefindthejob") is fine.

## Use by deploying institutions

Beratungsstellen, Jobcenter, university career services, NGOs, and other
institutional adopters may identify their deployment as being "powered by
Helpmefindthejob" or "an instance of Helpmefindthejob" without requesting
permission, provided the deployment is a substantially unmodified version
of the upstream project and the attribution is honest. For materially
modified deployments, please use a distinct name (see the previous
section).

## Future trademark registration

If the project's institutional wrapper (The Commons Conservancy or a
successor body) decides to register one or more of these marks formally,
this policy will be updated accordingly. Until then, the marks are
unregistered and asserted in good faith by the maintainers.

## Reporting trademark concerns

If you believe a third party is misusing the project's marks in a way that
confuses users or misrepresents the upstream project, please open a private
report via the channel listed in [SECURITY.md](SECURITY.md). Trademark
disputes are handled by the maintainers (and, once admitted, in
coordination with The Commons Conservancy).

## Inspiration

This trademark policy follows the pattern used by Tenzu and other
Commons-Conservancy-hosted projects: a short, fork-friendly statement that
keeps copyright and trademark cleanly separated.
