# Code of Conduct

DirectJob Scout adopts the Contributor Covenant version 2.1 as its Code of Conduct.

The full text is available at the canonical source:
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

The Covenant establishes that contributors and maintainers commit to making participation in the project welcoming for everyone regardless of background. It defines expected behavior, unacceptable behavior, enforcement responsibilities, and enforcement procedures. Read the linked document in full before participating in project spaces.

## Reporting

Concerns about behavior in any project space — the source repository, issue tracker, discussions, mailing lists, third-party platforms used in the project's name, and any in-person events — may be reported to the maintainer via the contact information in AUTHORS.md. Once the project domain is registered, a dedicated reporting address will be added here.

Anonymous reports are accepted through the same channel. Reports are handled per the Covenant's Enforcement Responsibilities and Enforcement Guidelines sections.

## Scope

This Code of Conduct applies within all project spaces and when an individual represents the project in public — including official communications, project events, and online interactions involving the project's name.
