## What this is

Helpmefindthejob is an **open-source EU-wide civic-employment commons** — an MCP-composable copilot that captures specialist HR and bureaucratic-navigation knowledge into modular, standards-anchored tools and puts it directly into the hands of anyone facing structural friction between their actual capability and the European labor market's ability to recognise and connect them to work. Migrants and EU-mobile workers are the **most acute** use case and the primary narrative anchor in our proposals and demos; the same architecture serves career changers, workers returning after caregiving or extended absence, the long-term unemployed, returning expats, older workers, and first-generation graduates without family-networked guidance.

The seven-persona panel ([`docs/grant/07-personas.md`](../grant/07-personas.md)) — Aïcha, Yusuf, Olga, Mahmoud, Maria, Käthe, Tobias — anchors the design and the public artefacts. The project is licensed Apache 2.0 with a Contributor License Agreement; institutional wrapper is The Commons Conservancy (intake submitted; parallel-track per WinningPlan.MD v3).

The version-number jump is intentional. Between v0.1.0 (2026-05-18) and v0.80.0 (this release), the project shipped ~300 commits across the 4-week NLnet pre-submission sprint:

- The complete governance pack (LICENSE + NOTICE + 10 governance files at repo root)
- Repository rename + sanitisation (per Decision 22)
- Friction-class architecture re-anchoring (per Decision 21)
- 7 persona-walk transcripts under `docs/persona-walks/`
- Self-host tutorial, MCP integration guide, API client examples under `docs/`

- 3359-test unit suite (was 1029 at v0.1.0 — +2313 tests)
- CHANGELOG `[Unreleased]` section filled in with 13 sub-headings of content

`APP_VERSION` in `app.py` has tracked 0.80.0 internally since the pre-submission slice; the v0.80.0 tag aligns the cryptographic + git surface with the in-code declaration. Future post-grant work will follow normal SemVer cadence from this anchor (v0.81.0 minor, v0.81.1 patch, etc.).

## Reproducible build

Nix flake at repo root pins `nixos-25.05`. To reproduce:

```bash
git clone --depth 1 --branch v0.80.0 https://github.com/maksodf/helpmefindthejob.git
cd helpmefindthejob
nix develop --command python3 -m unittest discover -s tests
# Expected: Ran 3359 tests, OK (skip count is environment-conditional: ~35 on py3.12)
```

Or via Docker (no Nix):

```bash
docker build -t helpmefindthejob:v0.80.0 .
docker run --rm \
  -e HELPMEFINDTHEJOB_AUDIT_SALT="$(python3 -c 'import base64,secrets; print(base64.b64encode(secrets.token_bytes(32)).decode())')" \
  helpmefindthejob:v0.80.0 \
  python3 -m unittest discover -s tests
```
