# DirectJob Scout v0.1.0

**Released**: 2026-05-18

The first stable pre-publication tag of the project then known as
**DirectJob Scout** (identity-of-record at release time). On
2026-05-19, after this release shipped, the project was renamed to
**Helpmefindthejob** ([Decision 22](../grant/04-research-and-decisions.md#decision-22-project-rename--directjob-scout--helpmefindthejob),
canonical domain `helpmefindthejob.com`). The v0.1.0 cryptographic

## What this is

Helpmefindthejob is an **open-source EU-wide civic-employment commons**
— an MCP-composable copilot that captures specialist HR and
bureaucratic-navigation knowledge into modular, standards-anchored
tools and puts it directly into the hands of anyone facing structural
friction between their actual capability and the European labor
market's ability to recognise and connect them to work. Migrants and
EU-mobile workers are the **most acute** use case and the primary
narrative anchor in our proposals and demos; the same architecture
serves career changers, workers returning after caregiving or extended
absence, the long-term unemployed, returning expats, older workers,
and first-generation graduates without family-networked guidance. The
seven-persona panel ([`docs/grant/07-personas.md`](../grant/07-personas.md))
— Aïcha, Yusuf, Olga, Mahmoud, Maria, Käthe, Tobias — anchors the
design and the public artifacts. The project is licensed under
**Apache 2.0** with a Contributor License Agreement and is being
prepared as a **Programme of [The Commons Conservancy](https://commonsconservancy.org/)**
(NLnet-co-founded Dutch stichting); the application is pending case-
officer review. The project is **built with EU AI Act compliance-supporting controls** for
the 2 August 2026 enforcement date — every institution that deploys
the agent starts from a compliance-supporting configuration (the deployer retains its own legal review), avoiding the €30–200k of
external consulting that retrofit compliance would otherwise require.
The MCP server exposes the project as composable civic infrastructure
so parallel open civic agents — housing, healthcare, residency,
education — can compose with Helpmefindthejob in a single conversation
without forking either project.

This v0.1.0 release is the **first stable pre-publication tag**: a
deliberate landmark to which the upcoming NLnet NGI Zero Commons Fund
application points. The project's broader public launch is anticipated
during 2026 Q3 — see [`ROADMAP.md`](../../ROADMAP.md).

## Verifying this release

The annotated git tag `v0.1.0` points at the commit that includes
[`CHANGELOG.md`](../../CHANGELOG.md), [`ROADMAP.md`](../../ROADMAP.md),
and this file.

**The release source tarball is cosign-signed and ships with a
CycloneDX SBOM** (Week 4 task 4.2 of the grant sprint, landed
2026-05-19). Full verification commands + the signing-key
model + the future-keyless plan are documented at
[`v0.1.0-signing.md`](v0.1.0-signing.md). One-liner (download the
signed artefact by name; do **not** use `--archive=tar.gz` post-rename
— the auto-generated archive's bytes won't match the signed SHA-256):

> **Prerequisite**: the maintainer must attach the original signed
> `directjob-scout-0.1.0.tar.gz` as a v0.1.0 release asset before any
> post-rename verifier can run the commands below. Tracked as a
> maintainer action in [`CONTRIBUTORS-NOTE.md`](../../CONTRIBUTORS-NOTE.md).

```bash
gh release download v0.1.0 \
  --pattern 'directjob-scout-0.1.0.tar.gz' \
  --output v0.1.0-source.tar.gz
gh release download v0.1.0 \
  --pattern 'v0.1.0-source.tar.gz.sigstore' \
  --pattern 'v0.1.0-cosign.pub'
cosign verify-blob v0.1.0-source.tar.gz \
  --key v0.1.0-cosign.pub \
  --bundle v0.1.0-source.tar.gz.sigstore \
  --insecure-ignore-tlog
# → Verified OK
```

The `--insecure-ignore-tlog` flag is required for v0.1.0
specifically because the signing key is a long-lived ECDSA P-256
key (cosign model b) not registered with the Sigstore transparency
log; the future keyless workflow (planned for v0.2.0+ via GitHub
Actions OIDC) removes the flag. See `v0.1.0-signing.md` for the
full key-model + rotation policy.

The full chain of trust for v0.1.0 is now: GitHub repository →
branch protection → annotated tag → cosign-signed source tarball
([`v0.1.0-source.tar.gz.sigstore`](v0.1.0-source.tar.gz.sigstore))
→ CycloneDX SBOM ([`v0.1.0-sbom.json`](v0.1.0-sbom.json)) listing
the 91 pinned dependencies the v0.1.0 venv resolved to.
