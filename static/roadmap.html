How to read this page

Language convention: we plan to, scoped for, anticipated, under consideration — never we will. The work below is plan, not promise.

  • In progress — work is actively underway; you can see commits landing on main
  • Scoped — the work is planned and the resources are in view
  • Anticipated — the work depends on prior milestones landing as expected
  • Under consideration — the work is on the long horizon; the actual quarter could shift
