API Reference

OpenAPI 3.1 specification for the public REST surface. Same-origin spec at /api/openapi.json — no third-party JS, no CDN fetches.

Die API-Referenz ist auf Englisch — technische Inhalte sind sprachneutral.

About this reference

This page renders the OpenAPI 3.1 spec at /api/openapi.json as a navigable HTML reference. The spec covers every unauthenticated endpoint plus the auth-bootstrap flow. Admin-scoped and per-user data endpoints are excluded — federated deployers consult the source for those (they vary per deployment policy).

The deeper MCP-protocol surface (15 tools, JSON-Schema validated) lives at /mcp/schemas.json and is documented in docs/mcp-server.md.

Authentication

Endpoints under /api/admin/* and the per-user data endpoints (under /api/companies, /api/discovered-jobs, etc., not shown here) require a session cookie and a CSRF token (X-CSRF-Token header on every mutating request). Get the session by calling POST /api/auth/login; the response carries the CSRF token in the user.csrfToken field.

Public endpoints (everything in this reference) are unauthenticated.

Versioning

The API version matches the application version (/api/version). Breaking changes get a major-version bump and are listed in the changelog. Phase-1 (NLnet grant window) commits to stability of the surface documented above.
