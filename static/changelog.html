# 0.79 — first public release · 2026-05-22 / 23

Six rapid minor releases (0.74 → 0.79.4) landed across two weeks while preparing the project for the NLnet NGI Zero Commons Fund application. Highlights below; full per-commit detail in CHANGELOG.md at the repo root.

  • Project rename: DirectJob Scout → Helpmefindthejob (per Decision 22). All 271 affected files swept; cryptographic identity-of-record (v0.1.0 cosign signature) preserved.
  • TLD pivot: canonical domain moved from helpmefindthejob.com → helpmefindthejob.org (Decision 22 amendment). Driver: DNSSEC at the .com blocked the cutover within the NLnet window; .org also better signals civic-commons positioning.
  • EU AI Act compliance scaffolding: Privacy page substantiates Articles 12 (HMAC-chain audit log), 13 (transparency), 14 (human oversight), 20 (portable export), 26 (deployer obligations), 50 (AI-generated content marking).
  • GDPR Articles 15–22 enumerated with concrete user-action paths; DPO statement (none required at current scale per Article 37); supervisory authority named (BlnBDI Berlin) with Article 77 complaint right.
  • Bilingual legal pages (DE+EN) for privacy, terms, data-retention, impressum. Server-side language resolver (?lang= > cookie > Accept-Language > default). Language switcher on every legal page.
  • WCAG-AA form accessibility: every input/select/textarea now has a programmatic label (95/95 via <label for=> or aria-label). Every HTML5 required control also has aria-required="true"; every hint span wired via aria-describedby.
  • CSP enforcement actually works: 12 inline style="..." attributes lifted to CSS classes; status-page inline <script> extracted to /status.js. Production CSP was previously silently blocking these.
  • Icon coverage: multi-resolution /favicon.ico (4 frames), /apple-touch-icon.png (180×180), /icons/og-card.png (1200×630) — all linked from every public page.
  • SEO: sitemap + robots + JSON-LD URLs now all use the apex (was leaking the demo. subdomain). robots no longer Allow-lists 404'd /jobs/ + /share/ paths. /mcp/ public catalogue explicitly Allow'd.
  • Impressum: filled with real operator legal data (was shipping with [OPERATOR FILL: …] placeholders — a §5 TMG liability).
  • Operational hardening: daily backup cron with B2 off-site rclone push (7-day local rotation), external UptimeRobot monitor, health-history bounded ring buffer, Prometheus /api/metrics endpoint.
  • Test suite: 2906 → 2931 (+25 root-cause regression guards). Every audit fix carries a test that would catch the regression.
