Was niemals gespeichert wird

  • API-Schlüssel von KI-Anbietern im Klartext.
  • Sitzungsbezogene API-Schlüssel, die in die Oberfläche eingegeben werden; sie werden einmalig übermittelt und anschließend verworfen.
  • Seiten beschränkter Plattformen (LinkedIn, XING, StepStone, Indeed) — diese werden bereits beim Abruf blockiert.

Löschungsersuchen

Sie können die Löschung Ihres Kontos unter Einstellungen → Datenschutz → Löschung beantragen beantragen; ein Administrator bestätigt das Ersuchen und führt Administration → Testkonten → Löschen aus. Die kaskadierte Löschung entfernt Unternehmen, Scans, gefundene und importierte Stellen, gespeicherte Suchen, Support-Tickets, Analyse-Ereignisse, Voreinstellungen für KI-Anbieter sowie aktive Sitzungen. Sicherungskopien werden gemäß der konfigurierten Aufbewahrungsfrist gelöscht.

Vor der Löschung kann ein Administrator Ihre Daten archivieren, indem er GET /api/admin/users/<id>/export aufruft. Die Antwort folgt demselben JSON-Schema wie Einstellungen → Sicherung & Wiederherstellung → Sicherung exportieren, beschränkt auf das jeweilige Zielkonto. Die Aktion wird im Administrations-Audit-Log als export_user_data protokolliert.
